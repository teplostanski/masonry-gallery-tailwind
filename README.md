# Masonry Gallery

An image gallery with a Pinterest-style masonry layout. Clicking an image opens a fullscreen modal with swipe navigation.

![Gallery screenshot](./screen.png)

## Demo

[Masonry Gallery](https://teplostanski.github.io/masonry-gallery-tailwind/)

## Stack

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **NextUI**
- **Swiper**


## Features

- Responsive `masonry` layout
- Fullscreen viewing
- Gesture support
- Responsive design
- Modern UI

## Running locally

1. Clone the repository:
```bash
git clone https://github.com/teplostanski/masonry-gallery-tailwind.git
cd masonry-gallery-tailwind
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

To build the project:
```bash
npm run build
```
